# 📄 DocTools — أدوات مستندات محلية 100%

أداة مستندات شخصية تعمل بالكامل على جهازك بدون أي إنترنت: لا رفع ولا تتبيع ولا أي اتصال خارجي — السيرفر يستمع على `127.0.0.1` فقط.

## المميزات (4 تبويبات)

| التبويب | الوظيفة |
|---|---|
| **محوّل الصيغ** | تحويل بين ~60 صيغة (PDF، Word، صور، جداول، كتب epub، بيانات، أرشيفات…) مع تقبّل أي ملف حتى لو امتداده بيكذب (تحليل المحتوى الحقيقي) |
| **تفريغ نص OCR** | استخراج نص من صور/PDF/Word بمحرك OCR الويندوز المدمج (عربي/إنجليزي/فرنسي) مع تنسيقات واتجاه RTL/LTR |
| **تحليل وفحص** | تحليل مجلد كامل: شجرة بكل الطبقات، إحصائيات الامتدادات، فحص نوع كل ملف الحقيقي vs امتداده (كشف الملفات المخادعة/الخبيثة)، وفتح وفحص جوه المضغوطات |
| **إنشاء مستند** | محرر بلوكات (نص/صور بترتيب وسحب) وتصدير لـ PDF/Word/PPT/PNG/HTML/Markdown/نص بضبط عربي صحيح |

## التشغيل من المتصفح (Web)

```bash
pip install -r requirements.txt
python run.py
```

هيفتح المتصفح على `http://127.0.0.1:8750` أوتوماتيكياً.

## التشغيل كتطبيق سطح مكتب (Desktop)

```bash
pip install pywebview
pythonw desktop.pyw
```

نافذة مستقلة بدون متصفح (بدون شريط عنوان ولا تبويبات). لتثبيتها في قائمة Start: ابحث عن **DocTools** ← كليك يمين ← **Pin to Start**.

## متطلبات

- Windows 10/11 (التفريغ OCR يستخدم محرك ويندوز المدمج)
- Python 3.12+
- `requirements.txt` — مكتبات محلية فقط (PyMuPDF، fpdf2، Pillow، python-docx، openpyxl…)

## الخصوصية

- لا يوجد أي اتصال خارجي: كل المعالجة على جهازك.
- لا حسابات، لا تتبع، لا تخزين سحابي.
