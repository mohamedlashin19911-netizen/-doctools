# 📄 DocTools — أدوات مستندات محلية 100%

أداة مستندات شخصية تعمل بالكامل على جهازك **بدون أي إنترنت**: لا رفع ولا تتبيع ولا اتصال خارجي — السيرفر يستمع على `127.0.0.1` فقط، وكل المعالجة (تحويل، OCR، فحص، تصدير) بتتم على جهازك.

---

## ⬇️ التحميل (Download)

**الطريقة 1 — أسهل (ZIP):**
1. من صفحة المشروع دوس على الأخضر **Code** ← **Download ZIP**
2. فك الضغط في أي مجلد (مثلاً `C:\DocTools`)

**الطريقة 2 — Git:**
```bash
git clone https://github.com/mohamedlashin19911-netizen/-doctools.git
```

**المتطلبات (مرة واحدة):**
```bash
pip install -r requirements.txt
pip install pywebview        # مطلوب فقط لوضع سطح المكتب
```
- Windows 10/11 + Python 3.12 أو أحدث
- وضع Desktop بيستخدم محرك WebView2 المدمج في ويندوز (موجود افتراضياً)

---

## 🌐 التشغيل من المتصفح (Web)

```bash
python run.py
```
هيفتح المتصفح أوتوماتيك على `http://127.0.0.1:8750`. (لو مقفش، افتحه انت واكتب العنوان.)

## 🖥️ التشغيل كتطبيق سطح مكتب (Desktop)

```bash
pythonw desktop.pyw
```
نافذة مستقلة بدون متصفح — بدون شريط عنوان ولا تبويبات. السيرفر بيشتغل جواها أوتوماتيك.

### التثبيت في قائمة Start
من **نسخة الويب** في نفس الجهاز: دوس زرار **«🖥️ ثبّت كتطبيق»** في الهيدر — هيتم إنشاء اختصار **DocTools** في قائمة Start تلقائياً، وبعدها تقدر تثبته للأبد: **كليك يمين على DocTools ← Pin to Start**.
(الزرار بيظهر في نسخة الويب فقط، ومش موجود داخل التطبيق نفسه.)

### الإلغاء
احذف الاختصار من:
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\DocTools.lnk`

## ✨ المميزات (4 تبويبات)

| التبويب | الوظيفة |
|---|---|
| **محوّل الصيغ** | تحويل بين ~60 صيغة: PDF، Word، صور (png/jpg/webp/avif/ico/eps…)، جداول (xlsx/csv/tsv)، كتب (epub/cbz)، بيانات (json/yaml/toml)، أرشيفات (zip/7z/tar)، نصوص (md/html/rtf) — بيتعرّف على النوع الحقيقي من **محتوى** الملف مش من الامتداد |
| **تفريغ نص OCR** | استخراج نص من صور/PDF/Word بمحرك OCR الويندوز المدمج (عربي/إنجليزي/فرنسي)، مع تنسيقات (عادي/فقرات/منظم)، اتجاه RTL/LTR، وسطر فاصل اختياري |
| **تحليل وفحص** | تحليل مجلد كامل: شجرة بكل الطبقات، إحصائيات الامتدادات والتصنيفات، فحص **النوع الحقيقي vs الامتداد** لكل ملف لكشف الملفات المخادعة/الخبيثة (exe متنكر كـ PDF مثلاً)، مع فتح **جوه المضغوطات** وفحص أعضائها (بما فيها الأرشيفات المتداخلة)، ويدعم سحب وإفلات المجلدات |
| **إنشاء مستند** | محرر بلوكات بالسحب والترتيب، وصور ونصوص، وتصدير إلى PDF/Word/PPT/PNG/HTML/Markdown/TXT مع تشكيل عربي صحيح |

## 🔒 الخصوصية

- لا يوجد أي اتصال خارجي — جرب فصل الإنترنت والتأكد بنفسك.
- لا حسابات، لا تتبع، لا تخزين سحابي، ولا CDN ولا خطوط من النت (كل الأصول محلية).
- الملفات اللي بترفعها من المتصفح للتحليل بتفضل في ذاكرة السيرفر المحلي لحظياً وبتمسح بعد العملية.
